# ตัวเชื่อมเครื่องพิมพ์ครัว (Kitchen Print Agent)

โปรแกรมเล็กๆ ตัวนี้จะคอยเช็คออเดอร์ใหม่จากเว็บสั่งอาหาร แล้วสั่งพิมพ์ใบสั่งออกเครื่องพิมพ์ครัว
ของคุณโดยอัตโนมัติ ผ่านเครือข่าย (WiFi/LAN) — ไม่ต้องกดพิมพ์เอง

**สำคัญ:** โปรแกรมนี้ต้องรันอยู่บนคอมพิวเตอร์เครื่องหนึ่ง (Windows หรือ Mac ก็ได้ เช่น
PC เก่า, มินิพีซี, หรือ Mac เครื่องเก่าที่มีอยู่แล้ว) ที่ต่ออยู่ใน **เครือข่ายเดียวกับเครื่องพิมพ์**
และเปิดทิ้งไว้ตลอดเวลาร้านเปิด (รันบนแท็บเล็ตที่ใช้เปิดหน้าจอครัวไม่ได้ เพราะแท็บเล็ตรันโปรแกรม
Node.js ไม่ได้)

## สิ่งที่ต้องมี

1. คอมพิวเตอร์ 1 เครื่อง ต่อ WiFi/LAN วงเดียวกับเครื่องพิมพ์ครัว (ใช้เครื่องเก่าที่มีอยู่แล้วก็ได้)
2. ติดตั้ง [Node.js](https://nodejs.org) (เวอร์ชัน 18 ขึ้นไป) บนเครื่องนั้น
3. รู้ **หมายเลข IP ของเครื่องพิมพ์** — ปกติดูได้จากเมนูบนตัวเครื่องพิมพ์เอง (Network Settings /
   Print Test Page มักมี IP โผล่มาด้วย) หรือถามช่างที่ติดตั้งเครื่องพิมพ์ให้

## ติดตั้ง (ไม่ต้องพิมพ์คำสั่งเองแล้ว)

ระบบนี้ใช้ได้ทั้งคอม **Windows** และ **Mac** เลือกทำตามฝั่งที่ตรงกับคอมเครื่องที่จะใช้รันได้เลย
(ไฟล์ในซิปมีให้ครบทั้งสองแบบ ไม่ต้องดาวน์โหลดเพิ่ม)

แตกไฟล์ zip นี้ไว้ในเครื่องที่จะรันก่อน (จำตำแหน่งโฟลเดอร์ไว้ ห้ามย้ายไปที่อื่นทีหลัง) แล้วเลือก:

### ถ้าใช้คอม Windows

1. ดับเบิลคลิกไฟล์ **`setup-shortcuts.vbs`** ในโฟลเดอร์นี้ครั้งเดียว — จะขึ้นเตือนสีฟ้าจาก
   Windows ว่า "Windows protected your PC" เพราะเป็นไฟล์ที่ดาวน์โหลดมา ให้กด **"More info"**
   แล้วกด **"Run anyway"** (ปลอดภัย เป็นสคริปต์ที่มากับไฟล์นี้เอง) จะมีข้อความแจ้งว่าตั้งค่าเสร็จ
   ขั้นตอนนี้จะทำ 2 อย่างให้อัตโนมัติ:
   - เพิ่มไอคอน **"เปิดระบบพิมพ์ครัว"** ที่หน้าจอ Desktop กดครั้งเดียวเปิดระบบได้เลยเหมือนแอป
   - ตั้งให้ระบบพิมพ์เปิดทำงานเองทุกครั้งที่เปิดคอมเครื่องนี้ ไม่ต้องกดอะไรอีก
2. ดับเบิลคลิกไอคอน **"เปิดระบบพิมพ์ครัว"** ที่เพิ่งเพิ่มบน Desktop เพื่อเริ่มใช้งานครั้งแรก
   ครั้งแรกจะติดตั้งไฟล์ที่จำเป็นให้อัตโนมัติ (รอสักครู่ ห้ามปิดหน้าต่างที่เด้งขึ้นมา) ครั้งต่อๆ ไป
   จะเปิดเร็วทันที

### ถ้าใช้ Mac

1. คลิกขวา (หรือกด Control ค้างแล้วคลิก) ที่ไฟล์ **`setup-shortcuts-mac.command`** ในโฟลเดอร์นี้
   → เลือก **"Open"** (ครั้งแรกเท่านั้นต้องเปิดแบบนี้ ห้ามดับเบิลคลิกตรงๆ เพราะ Mac จะบล็อกไฟล์
   ที่เพิ่งดาวน์โหลดมา) จะมีเตือนว่าไฟล์นี้มาจากอินเทอร์เน็ต ให้กด **"Open"** อีกครั้งเพื่อยืนยัน
   - Mac อาจถามขอสิทธิ์ควบคุม "System Events" ให้กด **Allow/OK** (ใช้สำหรับตั้งเปิดอัตโนมัติ)
   - ขั้นตอนนี้จะเพิ่มไอคอน **"🖨️ เปิดระบบพิมพ์ครัว"** ที่หน้าจอ Desktop และตั้งให้ระบบพิมพ์
     เปิดทำงานเองทุกครั้งที่เข้าใช้ Mac เครื่องนี้
2. ครั้งแรกที่เปิดไอคอน **"🖨️ เปิดระบบพิมพ์ครัว"** บน Desktop ก็ให้คลิกขวา → Open เหมือนกัน
   (ครั้งเดียวเท่านั้น) ครั้งต่อๆ ไปดับเบิลคลิกได้ปกติ ครั้งแรกจะติดตั้งไฟล์ที่จำเป็นให้อัตโนมัติ
   (รอสักครู่ ห้ามปิดหน้าต่างที่เด้งขึ้นมา)

### ดูสถานะเชื่อมต่อเครื่องพิมพ์

ทุกรอบที่เช็คออเดอร์ใหม่ โปรแกรมจะลองต่อเข้าเครื่องพิมพ์แต่ละเครื่องแบบเบาๆ (ไม่พิมพ์จริง)
แล้วส่งผลไปที่หน้าเว็บแอดมิน แท็บ "เครื่องพิมพ์ครัว" จะขึ้นจุดสีเขียว/แดงบอกว่าเครื่องพิมพ์
แต่ละเครื่องเชื่อมต่อได้อยู่ไหม แบบเรียลไทม์ — ไม่ต้องมาคอยดู Terminal เอง (แต่ถ้าอยากดูใน
Terminal ก็ยังมีบรรทัด `[printer] ✅/❌ ...` ขึ้นให้เห็นตอนสถานะเปลี่ยนเหมือนกัน)

### ทั้งสองแบบ: เพิ่ม/ตั้งค่าเครื่องพิมพ์ทั้งหมดได้จากหน้าเว็บแอดมินเลย
   (เข้า `/admin.html` → แท็บ "เครื่องพิมพ์ครัว") — โปรแกรมจะดึงรายชื่อเครื่องพิมพ์ทั้งหมด
   จากเว็บมาใช้เองอัตโนมัติทุกครั้งที่เช็คออเดอร์ ไม่ต้องมาแก้ไฟล์ในเครื่องคอมอีก

   **รองรับหลายเครื่องพิมพ์:** เพิ่มเครื่องพิมพ์ได้กี่เครื่องก็ได้ในหน้าแอดมิน แล้วเลือกว่าแต่ละ
   เครื่องพิมพ์เฉพาะเมนูหมวดไหน (เช่น เครื่องในครัวพิมพ์กับข้าว เครื่องหน้าบาร์พิมพ์เครื่องดื่ม)
   ออเดอร์เดียวจะถูกแยกพิมพ์ไปยังเครื่องที่ถูกต้องอัตโนมัติ ถ้าเมนูไหนไม่ได้ระบุหมวดหมู่ไว้กับ
   เครื่องพิมพ์เครื่องใดเลย จะไปออกที่ "เครื่องหลัก" (เครื่องที่ไม่ได้เลือกหมวดหมู่ไว้)
   ถ้ามีเครื่องพิมพ์แค่เครื่องเดียวและไม่เลือกหมวดหมู่อะไรเลย ก็จะพิมพ์ทุกออเดอร์ที่เครื่องนั้นเครื่องเดียว

   เปิดไฟล์ `config.json` ที่แตกมาแค่ 4 ค่านี้พอ (ไม่ต้องแก้ก็ได้ถ้าไม่เปลี่ยนเว็บ/ความถี่):
   - `apiBase` — ลิงก์เว็บสั่งอาหารของร้าน (ใส่ให้แล้ว ไม่ต้องแก้ถ้ายังใช้ลิงก์เดิม)
   - `pollIntervalMs` — ความถี่ในการเช็คออเดอร์ใหม่ (ค่าเริ่มต้น 6 วินาที)
   - `settingsRefreshMs` — ความถี่ในการโหลดรายชื่อ/ค่าตั้งเครื่องพิมพ์ใหม่ (ค่าเริ่มต้น 5 นาที)
   - `printerStatusHeartbeatMs` — ความถี่สูงสุดที่ส่งสัญญาณว่ายังทำงานอยู่ไปหน้าแอดมิน (ค่าเริ่มต้น 60 วินาที)

   แม้จะลดการดึงค่าตั้งและรายงานสถานะลง ระบบยังเช็คออเดอร์ใหม่ทุก 6 วินาที
   การพบออเดอร์ใหม่จึงอาจช้ากว่าค่าเดิมได้สูงสุด 2 วินาที

   ค่า `printers` / `paperWidthMm` / `shopName` ในไฟล์นี้จะถูกใช้เป็น
   **ค่าสำรอง** เผื่อโปรแกรมเชื่อมเว็บไม่ได้ชั่วคราวเท่านั้น ปกติไม่ต้องยุ่งกับมัน

## ทดสอบก่อนต่อเครื่องพิมพ์จริง (แนะนำ)

ยังไม่ต้องเสี่ยงกับกระดาษจริง ลองสั่งพิมพ์แบบ "ทดสอบ" ก่อนได้ ระบบจะไม่ยิงไปที่เครื่องพิมพ์
แต่จะเซฟรูปตัวอย่างใบสั่งเป็นไฟล์ .png ไว้ในโฟลเดอร์ `test-output` ให้ดูแทน:

```
npm run test-print
```

เปิดไฟล์ .png ที่ได้ดูว่าตัวหนังสือไทยขึ้นถูกต้อง จัดวางสวยงามไหม ก่อนเชื่อมเครื่องพิมพ์จริง

## รันจริง

ถ้าทำตามขั้นตอน "ติดตั้ง" ด้านบนแล้ว **ไม่ต้องทำอะไรเพิ่มเลย** — คอมเครื่องนี้จะเปิดระบบพิมพ์
ให้เองอัตโนมัติทุกครั้งที่เปิดเครื่อง/ล็อกอิน (ทั้ง Windows และ Mac)

หน้าต่าง Terminal สีดำที่เด้งขึ้นมาตอนเปิดคอม (เขียนว่า "ระบบเชื่อมเครื่องพิมพ์ครัวกำลังทำงานอยู่")
คือโปรแกรมกำลังทำงานอยู่ — **ห้ามปิดหน้าต่างนี้ตลอดเวลาร้านเปิด** จะลดขนาดหน้าต่างเก็บไว้ก็ได้
แต่ห้ามกดปิด (X) ถ้ากดปิดโดยไม่ตั้งใจ แค่เปิดไอคอน "เปิดระบบพิมพ์ครัว" บน Desktop ใหม่ได้ทันที
ระบบตั้งให้ลองเชื่อมต่อใหม่อัตโนมัติเองด้วยถ้าหลุดชั่วคราว

(สำหรับคนที่ถนัดใช้ Terminal ก็ยังรัน `npm start` เองตรงๆ ได้เหมือนเดิม)

## ปัญหาที่พบบ่อย

- **(Windows) เจอเตือนสีฟ้า "Windows protected your PC"** ตอนเปิด `setup-shortcuts.vbs` — ปกติ
  เกิดจาก Windows ยังไม่รู้จักไฟล์ที่เพิ่งดาวน์โหลดมา ไม่ใช่ไวรัส กด "More info" แล้วกด
  "Run anyway" ได้เลย
- **(Mac) เจอเตือน "cannot be opened because it is from an unidentified developer"** — ปกติ
  เกิดจากไฟล์ที่เพิ่งดาวน์โหลดมา ไม่ใช่ไวรัส ให้คลิกขวา (หรือกด Control ค้างแล้วคลิก) ที่ไฟล์
  แล้วเลือก "Open" แทนการดับเบิลคลิกตรงๆ (ทำครั้งแรกครั้งเดียวต่อไฟล์ ครั้งต่อไปดับเบิลคลิกได้ปกติ)
- **(Mac) อยากลบระบบเปิดอัตโนมัติออก** — เข้า System Settings → General → Login Items →
  หา "ระบบพิมพ์ครัว" แล้วกดลบ (เครื่องหมาย −)
- **อยากย้ายโฟลเดอร์นี้ไปที่อื่นทีหลัง** — Windows: ลบไอคอนเก่าที่ Desktop และในโฟลเดอร์ Startup
  ทิ้งก่อน (กด Win+R พิมพ์ `shell:startup` แล้วลบไฟล์ "ระบบพิมพ์ครัว.lnk") แล้วรัน
  `setup-shortcuts.vbs` ใหม่ในตำแหน่งใหม่ — Mac: ลบไอคอนเก่าที่ Desktop และเอาออกจาก Login
  Items ตามข้อด้านบนก่อน แล้วรัน `setup-shortcuts-mac.command` ใหม่ในตำแหน่งใหม่
- **"printer connection timed out"** — เช็คว่า IP ถูกต้อง เครื่องพิมพ์เปิดอยู่ และอยู่ WiFi/LAN
  วงเดียวกับคอมพิวเตอร์ที่รันโปรแกรมนี้จริงๆ (ร้าน Jinko ใช้ `ping 192.168.1.242`)
- **พิมพ์ออกมาแต่ตัวหนังสือเพี้ยน/ว่างเปล่า** — เครื่องพิมพ์บางรุ่นต้องตั้งค่า "Raster/Image
  printing" เปิดไว้ในเมนูเครื่อง (บางยี่ห้อปิดไว้เป็นค่าเริ่มต้น) ลองเช็คคู่มือเครื่องพิมพ์รุ่นนั้นๆ
- **ใบเสร็จกว้าง/แคบเกินกระดาษ** — แก้ `paperWidthMm` ใน config.json ให้ตรงกับกระดาษจริง (58 หรือ 80)
- **พิมพ์ซ้ำ / ไม่พิมพ์บางออเดอร์** — โปรแกรมจำออเดอร์ที่พิมพ์ไปแล้วไว้ในไฟล์ `printed.json`
  ถ้าลบไฟล์นี้ทิ้ง โปรแกรมจะพิมพ์ออเดอร์เก่าซ้ำทั้งหมดในรอบถัดไป (ปกติไม่ต้องยุ่งกับไฟล์นี้)

## หมายเหตุจากผู้พัฒนา

ระบบนี้ทดสอบเรื่องการเรนเดอร์ภาษาไทยและการเข้ารหัสคำสั่ง ESC/POS มาอย่างละเอียดแล้ว
แต่ **ยังไม่เคยทดสอบกับเครื่องพิมพ์จริง** (ไม่มีฮาร์ดแวร์ให้ทดสอบ) เครื่องพิมพ์แต่ละยี่ห้อ/รุ่น
อาจมีรายละเอียดปลีกย่อยต่างกันบ้าง แนะนำให้เริ่มจาก `npm run test-print` ดูตัวอย่างก่อน
แล้วค่อยลองพิมพ์จริงกับกระดาษ 1 ใบ ถ้าเจอปัญหาอะไรส่งข้อความมาบอกได้ จะช่วยแก้ให้ต่อ
